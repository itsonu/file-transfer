Three steps. No pairing.

  1. 1

    Start it

    Open Open Transfer on any computer. It shows a link and a QR code.

  2. 2

    Connect

    Scan the QR code with a phone camera, or type the link on any device on the same Wi‑Fi.

  3. 3

    Share

    Drop files on the page. They appear instantly on every connected device, ready to download.

Everything you’d expect. Nothing you don’t.

Any size, any number

Drag, pick or paste. Files stream straight to disk with live speed and time left — no size caps.

Stays on your network

Devices talk directly. Nothing is uploaded to a server, and the page loads nothing from the internet.

Optional PIN

Lock it on shared Wi‑Fi. The QR code signs people in, so it’s still one scan.

Live everywhere

New files show up on every device automatically. Delete with Undo. Download all as one ZIP.

Inbox & read-only modes

Collect files privately with --receive-only, or hand files out with --read-only.

Open & scriptable

MIT licensed. Docker image, reverse-proxy support and a small HTTP API for curl.

Run from source

Python 3.10+. One command sets everything up.

git clone https://github.com/itsonu/open-transfer.git
cd open-transfer
./run.sh          # Windows: .\run.ps1

Self-host with Docker

For a NAS, home server or Raspberry Pi.

docker run -d -p 5000:5000 \
  -v "$PWD/uploads:/data" \
  ghcr.io/itsonu/open-transfer

Questions

Is it safe?

Files never leave your network. Without a PIN, anyone on the same Wi‑Fi with the link can see shared files — so use --pin on public or shared networks. It includes CSRF and DNS-rebinding protection, rate-limited PINs, a strict Content-Security-Policy and path-safe file handling. See the security policy.

Does the other device need an app?

No. Any modern browser works — iPhone, Android, Windows, Mac, Linux, even smart TVs.

My phone can’t open the link.

Make sure both devices are on the same Wi‑Fi (guest networks often isolate devices) and that your computer’s firewall allows Open Transfer on private networks.

Is there a file size limit?

Only your free disk space. You can set one with --max-size 4G.
